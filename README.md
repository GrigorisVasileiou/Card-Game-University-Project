# Card-Game-University-Project
This project is a simple Java implementation of the card game Crazy Eights. It was created for learning purposes and focuses on practicing object-oriented programming concepts such as classes, objects, and game logic.

The program simulates a Crazy Eights game using a text-based (console) interface. It includes representations for cards, suits, players, hands, piles of cards, and the table. Each class is responsible for a specific part of
the game, making the code easier to understand and maintain.

The game flow is controlled by a main game class, which handles turns, card drawing, and basic game rules. Players interact with the game through the console, and no graphical interface is used.

Overall, this project demonstrates how a card game can be modeled in Java using clean and simple object-oriented design.
